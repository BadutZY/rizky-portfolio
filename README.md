# Pixel Play Portfolio

jadi sebelumnya saya sudah pernah membuat website ini, website ini dibuat sangat clean dan juga bagus untuk landing pagenya, atau pada bagian homenya itu sangat bagus dan sangat clean terlihatnya, coba anda buatkan dengan visual yang serupa seperti landing page home pada website ini, namun sekarang saya ingin membuatnya untuk portofolio saya yaitu badutzy.

saya ingin anda buatkannya dengan pixelated, jadi visualnya tetap seperti itu namun lebih pixelated lagi, jadi lebih bagus dan lebih clean lagi buatkannya, pastikan animasinya juga pixelated juga, dan komponen komponen lainnya juga pastikan pixelated, lalu untuk bagian saat ubah temanya juga buatkan animasinya sama, pastikan buatkan loading screen yang bagus pada saat diawal website di buka.

isi dari website ini adalah
Home
About
Skill
Project

di landing page atau di main page hanya ada ringkasan saja, jadi belum semua isinya, untuk penjelasan lebih detail tentang About, Skill, dan Project buatkan page masing masing agar lebih terlihat profesional, untuk Home tidak perlu di beri page baru, pastikan anda untuk membuatkan nya juga pixelated dan enak untuk dilihat, pastikan tidak ada animasi yang jelek dan juga tidak smooth, buatkan untuk tampilan mobile juga tetap terlihat bagus dan tidak jelek.

pastikan anda membuatkannya project react tanpa tanstak, jadi hanya react biasa saja dengan local host 8080, jadi agar bisa di deploy di vercel juga.
